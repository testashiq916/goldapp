SQL Clear — Daybook Table Fix

MySQL compatibility fix: DEFAULT curdate() removed for MySQL < 8.0.13

What Was Wrong
BEFORE
`tdate` date DEFAULT curdate(),
FIXED
`tdate` date DEFAULT NULL,

DEFAULT curdate() requires MySQL 8.0.13+. XAMPP ships with MySQL 5.7 where this causes a syntax error. The fix sets DEFAULT NULL and lets the application supply today's date on insert.

Complete Fixed SQL — Ready to Run
No curdate() — safe for all MySQL versions
If Table Already Exists — Run This ALTER
ALTER TABLE `daybook` MODIFY `tdate` date DEFAULT NULL;
How to Run in phpMyAdmin
1
Open http://localhost/phpmyadmin in your browser.
2
Select your database from the left panel.
3
Click the SQL tab at the top.
4
Paste the fixed SQL above and click Go.
Auto-Fill Today's Date in Laravel (Model)
// Add to your Daybook model (app/Models/Daybook.php)
protected static function boot() {
    parent::boot();
    static::creating(function ($model) {
        if (empty($model->tdate)) {
            $model->tdate = now()->toDateString(); // sets today's date
        }
    });
}
