2. Architecture Overview

Request Flow

Browser → routes/web.php → Controller → DB (MySQL) → JSON response → JS renders HTML

Module System

The application uses a single-page iframe model:

  • resources/views/native/dashboard.blade.php is the shell
  • Each module is a separate Blade view rendered inside an <iframe>
  • The moduleConfigMap JS object maps module IDs to URLs
  • Modules communicate with the parent via window.parent.postMessage()

Two-Layer API Pattern

Every module has two route types:

  1. Page route — GET /module-name → returns a Blade view
  2. API route — GET /api/module-name/data → returns JSON

The Blade view contains a <script> block that calls the API via fetch() and renders the table in the browser.

4. Key Coding Patterns

4.1 API Response Format

Always return flat JSON. JS reads fields directly from the response object.

// CORRECT return response()->json(['ok' => true, 'rows' => $rows, 'totals' => $totals]); // WRONG — do not nest data return response()->json(['ok' => true, 'data' => ['rows' => $rows]]);

4.2 Schema Guard Pattern

Always check table/column existence before querying — legacy tables may be missing optional columns:

// Guard entire table if (!Schema::hasTable('repairm')) { return response()->json(['ok' => true, 'rows' => []]); } // Guard optional column if (Schema::hasColumn('repairm', 'rbillno')) { $q->addSelect('m.rbillno'); }

4.3 GROUP BY — ONLY_FULL_GROUP_BY Fix

MySQL strict mode requires all non-aggregated SELECT columns to appear in GROUP BY. Fix: group only by the key/code column, use MAX() for display name columns.

// WRONG — causes SQL error 1055 ->groupBy('m.refcode', 'c.name') // CORRECT ->groupBy('m.refcode') ->selectRaw('MAX(TRIM(COALESCE(c.name, m.refcode))) as refinername') ->orderByRaw('MAX(c.name)')

4.4 f() Filter Helper (safe insert)

Used in transaction controllers to only insert columns that actually exist in the table:

private function f(string $table, array $data): array { static $cols = []; if (!isset($cols[$table])) { $cols[$table] = Schema::hasTable($table) ? array_map('strtolower', Schema::getColumnListing($table)) : []; } return array_filter($data, fn($k) => in_array(strtolower($k), $cols[$table], true), ARRAY_FILTER_USE_KEY ); }

4.5 Date Validation

private function date(Request $request, string $key): string { $v = (string) $request->query($key, date('Y-m-d')); return preg_match('/^\d{4}-\d{2}-\d{2}$/', $v) ? $v : date('Y-m-d'); }

4.6 Exit Button (module close)

All views must include this to allow the dashboard to close the iframe:

document.getElementById('exitBtn').addEventListener('click', () => window.parent.postMessage({type: 'goldapp:close-module-frame'}, '*') );

9. Dashboard Module System

moduleConfigMap

Located in dashboard.blade.php. Maps a string module ID to its URL and mode:

const moduleConfigMap = { 'sales-bill': { mode: 'iframe', url: '{{ url("/sales-bill/new") }}' }, 'remake-reports-remake-reports': { mode: 'iframe', url: '{{ url("/remake-reports/remake-reports?module=remake-reports-remake-reports") }}' }, // ... };

Menu Definition

The menu is a JS array of objects. Each item uses the helper m(label, moduleId, icon, shortcut?):

{ label: 'Remake', icon: 'fa-recycle', children: [ m('Remake Reports', 'remake-reports-remake-reports', 'fa-file-lines'), m('Remake Pending', 'remake-reports-remake-pending', 'fa-hourglass-half'), ]}

Module Close Signal

iframes signal the parent to close them by posting a message:

window.parent.postMessage({ type: 'goldapp:close-module-frame' }, '*');

10. How to Add a New Module

Step 1 — Create the Controller

php artisan make:controller MyNewReportController

Add page method + API data method. Use the session guard. Follow the flat JSON response pattern.

Step 2 — Create the View

Create resources/views/my-report/index.blade.php. Include:

  • Toolbar with date filters + Show/Print/Exit buttons
  • <table> with id="reportBody" and tfoot totals
  • JS fetch() call to the API endpoint
  • exitBtn postMessage handler

Step 3 — Add Routes

In routes/web.php, add the use statement and routes:

use App\Http\Controllers\MyNewReportController; Route::get('/my-report', [MyNewReportController::class, 'index']); Route::get('/api/my-report/data', [MyNewReportController::class, 'data']);

Step 4 — Add to Dashboard moduleConfigMap

In dashboard.blade.php, add to the moduleConfigMap object:

'my-new-report': { mode: 'iframe', url: '{{ url("/my-report?module=my-new-report") }}' },

Step 5 — Add to Menu

Find the appropriate menu section in dashboard.blade.php and add:

m('My New Report', 'my-new-report', 'fa-file-lines')

Step 6 — Clear Config Cache

php artisan config:clear php artisan route:clear php artisan view:clear

11. Report Pattern

All report views follow this standard pattern:

Controller Data Method

public function data(Request $request): JsonResponse { if (!$request->session()->has('user_code')) { return response()->json(['ok' => false], 401); } if (!Schema::hasTable('mytable')) { return response()->json(['ok' => true, 'rows' => []]); } $date1 = $this->date($request, 'date1'); $date2 = $this->date($request, 'date2'); $rows = DB::table('mytable as m') ->whereBetween('m.tdate', [$date1, $date2]) ->orderBy('m.tdate') ->get()->map(fn($r) => (array) $r)->values()->all(); $totals = [ 'amount' => array_sum(array_column($rows, 'amount')), ]; return response()->json(['ok' => true, 'rows' => $rows, 'totals' => $totals]); }

View JS Fetch Block

document.getElementById('filterForm').addEventListener('submit', async e => { e.preventDefault(); const p = new URLSearchParams({ date1: document.getElementById('date1').value, date2: document.getElementById('date2').value, }); const res = await fetch(`${API}?${p}`, { headers: { Accept: 'application/json' } }); const d = await res.json(); if (!d.ok) throw new Error(d.message || 'Error'); // render rows... });

12. Troubleshooting

Unknown column 'x' in field listColumn referenced is on detail table (d), not master (m)Change m.colname → d.colname
App connects to SQLite / wrong DBStale bootstrap/cache/config.phpphp artisan config:clear
Route not found (404)Route missing or controller use statement missingAdd route + use App\Http\Controllers\... to web.php
Module not opening in dashboardmoduleConfigMap entry missingAdd entry to moduleConfigMap in dashboard.blade.php
401 on API callSession expired or not logged inUser must re-login; check session timeout config
vendor/ folder 3+ GBNormal — Composer dependenciesNormal. Never delete. Run composer install to restore if missing.
