Daybook Table — SQL Date Error Fix

Problem: The daybook table uses DEFAULT curdate() on the tdate column.
This syntax is only supported in MySQL 8.0.13+. On older MySQL versions (common with XAMPP), this causes a syntax error.

1. Check Your MySQL Version

Run this query in phpMyAdmin or MySQL console:

SELECT VERSION();

If the result is below 8.0.13, you must use one of the fixes below.

2. Choose Your Fix

Option Method Best For
A Remove default, set date in PHP/Laravel Recommended for Laravel apps
B Use TIMESTAMP column with DEFAULT CURRENT_TIMESTAMP Quick SQL-only fix
C Use a TRIGGER to auto-set the date Keep DATE type, auto-fill on insert

Then in your Laravel Model, set the date automatically:

// In your Daybook model or controller
protected static function boot() {
    parent::boot();
    static::creating(function ($model) {
        if (empty($model->tdate)) {
            $model->tdate = now()->toDateString(); // sets today's date
        }
    });
}
